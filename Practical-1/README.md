# Practical 1: Portfolio Web Application

A responsive personal portfolio web application built with **React**, **Vite**, and **React Router**.

## Features

- **Home Page**: Hero section with introductory info and quick links.
- **About Page**: Detailed personal background and education.
- **Skills Page**: Interactive showcase of technical skills and tools.
- **Routing**: Seamless multi-page navigation using React Router.

## Project Structure

```text
Practical-1/
└── prac1-portfolio/
    ├── public/              # Static assets (favicons, icons)
    ├── src/
    │   ├── assets/          # Images and SVG icons
    │   ├── components/      # Reusable UI components (NavBar, Header, Footer, etc.)
    │   ├── pages/           # Page views (HomePage, AboutPage, SkillsPage)
    │   ├── App.jsx          # Route configuration
    │   └── main.jsx         # Application entry point
    ├── package.json
    └── vite.config.js
```

## Getting Started

1. Navigate to the project directory:
   ```bash
   cd prac1-portfolio
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm run dev
   ```
